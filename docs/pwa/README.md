# PWA rollout notes

## Enable

```bash
NEXT_PUBLIC_PWA_ENABLED=true
NEXT_PUBLIC_PWA_OUTBOX=true
NEXT_PUBLIC_PWA_MAIL_CACHE=true
NEXT_PUBLIC_PWA_BG_SYNC=true
```

Master flag defaults to **off**. Enable on staging first, then production.
